🔒 Privasi & Keamanan — Design-First

  • ✓ 100% Lokal: Semua pemrosesan di NAS, tidak ada data keluar dari komputer pengguna.
  • ✓ Face Recognition OFF default: Tidak ada data biometrik diproses kecuali user secara eksplisit mengaktifkan (BIPA/GDPR/UU PDP compliant).
  • ✓ Konfirmasi per aksi: Setiap operasi tulis (simpan klip, buat laporan) memerlukan persetujuan pengguna via UGOS confirmation gate.
  • ✓ Tanpa kredensial: Tidak ada API key, token, atau data pribadi yang disimpan dalam paket skill.
